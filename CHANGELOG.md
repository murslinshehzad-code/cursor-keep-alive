# Changelog

All notable changes to this project are documented here. The format follows
[Keep a Changelog](https://keepachangelog.com/en/1.1.0/).

## [0.1.0] - 2026-11-17

First public release.

### Added
- Background Chrome Remote Desktop session hosted in an almost transparent overlay, kept alive by a
  foreground service.
- Random touch swipes (random direction, length, speed and position) at random gaps of 1-30 seconds.
- Go dark mode: black screen at the lowest brightness that keeps the display on.
- Pause, resume and stop from the app and from the notification, with live status.
- Automatic reconnect, crash recovery and a sign-in-lost alert.
- Setup checklist, timing presets, advanced swipe settings, light and dark theme.
